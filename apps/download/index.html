ЕСТЬ ВОПРОСЫ?

Коротко и по делу

Откуда берётся музыка?

SONORA объединяет открытые и разрешённые музыкальные каталоги. Доступность конкретной записи и способ её воспроизведения зависят от условий источника.

Приложение бесплатное?

Базовый доступ к SONORA предоставляется бесплатно. Отдельные функции и источники могут иметь собственные ограничения.

Безопасно ли устанавливать APK?

Скачивай APK только из официального GitHub Releases SONORA и сверяй SHA-256. Не устанавливай файлы из неизвестных зеркал.

Есть ли версия для iPhone?

Сейчас на этой странице опубликована Android-версия. Доступность iOS-версии будет объявлена отдельно, когда появится готовый релиз.

Можно ли перенести плейлисты?

В SONORA развивается импорт медиатеки. Совпадения зависят от того, какие треки доступны в едином каталоге; импорт не скачивает защищённое аудио из других сервисов.
